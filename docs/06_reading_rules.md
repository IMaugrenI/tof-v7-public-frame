# How to Read This Architecture Reference

This repository retains a **version-tagged historical architecture reference**. Its purpose is to explain boundaries; it is not the operational source of truth for private systems.

## Interpretation rules

- Public architecture descriptions do not prove that the depicted services are running.
- Reduced examples are not a complete implementation.
- **V7** identifies the earlier architecture stage, not the maturity of today's public tools.
- Identity, symbolic language, and presentation cannot replace technical authorization or current state.
- Planning, workbench material, archive, canon, and runtime have different authority.
- Omitted private infrastructure and security details must not be filled in by guesswork.

## Practical next step

For working tools, features, installation steps, and known limitations, start with the [project overview](https://github.com/IMaugrenI/tof-showcase) and then the specific product repository.
