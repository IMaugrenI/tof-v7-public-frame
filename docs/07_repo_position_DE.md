# Einordnung dieser Referenz

Der Repository-Name `tof-v7-public-frame` bleibt erhalten, damit bestehende Links und die Entwicklungsgeschichte gültig bleiben. Seine öffentliche Aufgabe wird jetzt als **versionsbezogene Architekturreferenz** beschrieben, nicht als Haupteinstieg zu ToF Systems.

## Öffentliche Projektübersicht

| Repository | Aufgabe |
| --- | --- |
| [ToF Showcase](https://github.com/IMaugrenI/tof-showcase) | Zentrale Übersicht über öffentliche Werkzeuge, Architektur und Methoden |
| [Container Pulse](https://github.com/IMaugrenI/tof_container_pulse) | Lokale Infrastruktur schreibgeschützt beobachten |
| [Local Knowledge](https://github.com/IMaugrenI/tof_local_knowledge) | Lokale Dokumentensuche und beleggestützte Antworten |
| [Local Builder](https://github.com/IMaugrenI/tof_local_builder) | Kontrollierte lokale KI-gestützte Entwicklung |
| [Local Case Organizer](https://github.com/IMaugrenI/local_case_organizer) | Lokale Dokumentenorganisation und Export |
| [Recovery Workbench](https://github.com/IMaugrenI/tof-legacy-recovery-workbench) | Strukturierte Aufarbeitung älteren Materials |
| [Bridge Planning](https://github.com/IMaugrenI/tof-bridge-planning-method) | Geprüfter Übergang von Vorbereitung zur Planung |
| **Dieses Repository** | Frühere Architekturreferenz zu Systemgrenzen |

Dieses Dokument erklärt Architekturkonzepte und behauptet damit keinen Betriebszustand. Für tatsächliches Verhalten sind die Produkt-Repositories maßgeblich.
