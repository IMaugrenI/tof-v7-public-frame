# Start here

This repository is a **version-tagged architecture reference**, not a runnable product. The V7 identifier remains in its name for historical continuity; it is not required background for understanding the ideas.

> German version: [START_HERE_DE.md](START_HERE_DE.md)

If you have not seen the broader repo family yet, begin with [tof-showcase](https://github.com/IMaugrenI/tof-showcase).

## Read this repository in this order

1. [Core frame](docs/01_core_frame.md) — the reduced public view of V7.
2. [Space boundaries](docs/02_space_boundaries.md) — why runtime, canon, archive, Werkbank, and planning are kept separate.
3. [Public guardrails](docs/03_public_guardrails.md) — what can and cannot be inferred from the public material.
4. [Public chain](docs/04_public_chain.md) — the reduced processing-chain view.
5. [Reduced service map](docs/05_reduced_service_map.md) — selected public structural relationships.
6. [Reading rules](docs/06_reading_rules.md) — how to interpret the repository without turning documentation into runtime claims.

## What you should take away

After reading, you should understand:

- clear system boundaries matter beyond any particular bot or chat interface
- different spaces have different authority
- public explanation is deliberately less detailed than private operator/runtime truth
- planning, recovered material, canon, and runtime are not interchangeable

## What not to do with this repo

Do not treat it as:

- install instructions
- a deployable service map
- a complete production architecture
- proof that every internal component is public or currently active

For runnable public code, go to the product repositories linked from [tof-showcase](https://github.com/IMaugrenI/tof-showcase).
